# LinkedIn

Upwork's official MCP lets an agent read your freelancer account and submit a proposal only after you confirm it.

I put five open-source Agent Skills on top of that connector:

- find jobs and skip ones you already applied to
- score a job without treating missing client data as a failure
- draft a proposal from work that is actually on your profile
- show the Connects cost, and boost only if you pick the number
- review proposal statuses without inventing an interview rate

The proposal skill cannot press submit. Profile boost ads still start on upwork.com, because the API will not start that spend.

It is an independent project, not an Upwork product.

npx skills add saeed-pallivivo/upwork-jobpilot-skills

MCP login stays the official one: https://www.upwork.com/ai/mcp
