# Local profile

Copy this file to one of these paths and edit it. Those copies are gitignored:

- `.upwork-jobpilot/profile.md` in the project you are working in
- `profile.md` in that project
- `~/.upwork-jobpilot/profile.md`

The skills also read the live Upwork profile. This file is for work and preferences that the profile does not state. Leave a field out rather than guessing. Do not put secrets, passwords, or client private data here.

```markdown
# Profile

headline: Product engineer for React and Next.js
core_skills:
  - React
  - Next.js
  - TypeScript
experience_level: intermediate
industries:
  - B2B SaaS
preferred_technologies:
  - React
  - Next.js
proposal_tone: short

portfolio:
  - name: Scheduling app for a clinic
    url: https://example.com/scheduling
    stack: Next.js, TypeScript
    evidence: Shipped the booking flow and the staff calendar. Say this only if it is true.
  - name: Component library
    url: https://example.com/ui
    stack: React
    evidence: Published the documented components the team still uses.

achievements:
  - Maintained the scheduling app after launch.
```

The sample person and the example.com links are fiction. Replace them with work you can show a client.
